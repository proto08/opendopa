# 鉄軌道の損益・貸借: 0 は記載なし、極端な値は読まない

- 日付: 2026-11-06
- Issue: #54
- 決定: `rail_pl` / `rail_income` / `rail_bs` では、営業収益・営業損益・純損益・総資産・自己資本比率などの 0 を `zero_is_null` で欠損にする(事業別の営業損益の 0 は「その事業をしていない」)。営業損益が 0 の行は、黒字とも赤字とも言わないので動画にしない。営業係数は 1000% を超えたら読まず、総資産の絶対額は 1,000 千円未満なら読まない。`rail_pl` の `OPERATING_REVENUE_PER_CAR_KM_YEN` は、中央値が約21万円で単位が確認できないため原稿に使わない。
- 理由: 実データで、0 が「記載なし」として並んでいる(`BUS_*` の 0 が約 1,900 行、`TOTAL_ASSETS` の 0 が 26 行など)。営業係数は最大 729,792%、車キロあたりの営業収益は最大約 1.2 億円と、読み上げられない桁がある(§0.2: 元データにない意味づけをしない)。
