# BGM はフィード全体で 1 曲をループし、音源は設定で差し込む(同梱しない)

- 日付: 2026-11-07
- Issue: #146
- 決定:
  - 付け方はフィード全体で 1 曲(動画ごと・データセットごとにはしない)。行の音声とは別の `<audio>` でループさせ、`onended` は使わない。字幕の切り替えは行の音声の `ended` が基準のままで、BGM は関与しない。
  - 音量は既定 0.15(読み上げは 1.0)。`BGM_VOLUME` で 0〜1 に変えられる。ミュートは左下のボタン(`localStorage` に保存)。タブが隠れている間は止める。
  - 配信は `MEDIA_BASE_URL` 配下に置く(`BGM_FILE` は相対パス、または http(s) の URL)。設定は web が実行時に環境変数から読む(`BGM_FILE`・`BGM_CREDIT`・`BGM_VOLUME`)。
  - `BGM_FILE` と `BGM_CREDIT` の両方があるときだけ鳴らす。クレジットはフッターに、VOICEVOX のクレジットと並べて出す。
  - 自動再生が止められたら、#127 と同じく最初の操作(pointerdown / keydown)で鳴らし直し、その操作を一時停止として扱わない(`markUnlockGesture`)。
  - 音源のファイルはリポジトリに同梱しない。ライセンスを確認できた音源だけを、人が Blob に置いて環境変数で指す。
- 理由: 音源のライセンス・利用規約はこちらで確認できないため、仕組みだけを入れた。YouTube で使われている音源でも、再配布・アプリへの組み込みを許すとは限らない。1 曲のループなら、行の音声との同期や iOS の制約に影響しない。
- 関連: docs/design_doc.md §8.8
