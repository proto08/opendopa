# 絞り込み中の視聴・いいねも、通常どおり好みに反映する

- 日付: 2026-11-07
- Issue: #157
- 決定: タグで絞り込んでいる間も、`POST /api/view`・`POST /api/like` は変えず、好みの更新式(§7.2、§7.3)もそのまま使う。絞り込みは候補の集合(`candidateIds`)を狭めるだけで、`events` には何も足さない。「絞り込み中は学習しない」にはしない。
- 理由: 絞り込みで見たものも、そのユーザーが選んで見たもので、好みの手がかりとして有効。学習を止める分岐を足すと、`events` の再生(recsys が毎回 `view_events` と `like_events` から作る)に「そのとき絞り込み中だったか」の状態が要り、純粋関数の入力が増える。
- 関連: `docs/hashtag_design.md` §5.3、§11
