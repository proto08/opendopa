# /sleep のハーネスの自己改善は、PR とセルフレビューで行う

- 日付: 2026-11-07
- 決定: ハーネス(`.claude/` の手順書、`sleep-scan`)の不具合は、直接 push せず PR にする。別のサブエージェントがセルフレビューし、指摘なしなら、`/sleep` が `merge-rules.md` の条件でマージする(作成者以外のレビューが付かず、自動マージが成立しないため)。指摘は自分で直して指摘がなくなるまで繰り返す。`needs-human` は、設計から外れるなど人間の意思決定が要る場面だけに付ける。触ってよい範囲は `.claude/shared/harness-repair.md` の許可リストに限る。
- 理由: 直接 push は検証とレビューを飛ばす。仕組み自体を書き換えるので、変更の範囲を機械的に絞り、別の目で見る。テストは足さない(ハーネスの手順と文章が対象のため)。
