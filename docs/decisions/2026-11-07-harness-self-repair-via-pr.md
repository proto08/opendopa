# /sleep のハーネスの自己改善は、PR とセルフレビューで行う

- 日付: 2026-11-07
- 決定: ハーネス(`.claude/` の手順書、`sleep-scan`)の不具合は、直接 push せず PR にする。別のサブエージェントがセルフレビューし、指摘なしなら `status::ready-to-merge` で自動マージする。2周で通らなければ `needs-human`。触ってよい範囲は `.claude/shared/harness-repair.md` の許可リストに限る。
- 理由: 直接 push は検証とレビューを飛ばす。仕組み自体を書き換えるので、変更の範囲を機械的に絞り、別の目で見る。テストは足さない(ハーネスの手順と文章が対象のため)。
