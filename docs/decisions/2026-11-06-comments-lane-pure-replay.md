# コメントのレーンは、再生秒から純粋関数で再現する

- 日付: 2026-11-06
- Issue: #44
- 決定: 画面にいるコメントとそのレーンは、`activeComments(comments, totalSec, playedSec)` が累計の再生秒だけから求める(直近 8.5 秒の出し入れを先頭から再現)。レーンは「前のコメントが流れ終わるまで埋まる」とし、全部埋まっていればその回は出さない。流れる秒数(6〜8.5)は文字列と `t` のハッシュで決める。フッターは `position: fixed` で画面下端に重ねる。
- 理由: `useScenePlayer` の時計(`playedSec`)をそのまま使えば、一時停止・ループの連携に別の状態が要らない。同じ動画は毎回同じ見え方になる(§3.5 の決定性)。コメントが追いつかないよう、レーンは流れ終わるまで空けない。
