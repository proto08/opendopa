# 列の役割の推定順

- 日付: 2026-11-05
- Issue: #31
- 決定: 役割の推定は上から `coordinate`(列名が lat/lng/緯度/経度で値が範囲内)→ `flag`(数値で 0/1 のみ)→ `date`(9割以上が日付の形)→ `free_text`(文字列で最長 31 字以上)→ `id`(欠損以外の 98% 以上が一意。小数の列は除く)→ `number`(数値)→ `category`(種類数 20 以下かつ行数の半分以下)→ `other`。
- 理由: `free_text` を `id` より先にするのは、全行が異なる長い文(`INCIDENT_SUMMARY`)を id にしないため。しきい値は経験則で、データを見て調整する。
