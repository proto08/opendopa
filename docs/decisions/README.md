# 小さな決定(1決定1ファイル)

設計書の既定値から外れた判断や、実装中に決めた小さなことを、1決定につき1ファイルで置く。ファイルが別々なので、複数のPRが同時に決定を足しても衝突しない。

- ファイル名: `YYYY-MM-DD-<slug>.md`(日付は `date +%F`。slug は英小文字・数字・ハイフンの短い説明。同じ日に同名があれば slug を変える)
- 形式: 下のとおり。1ファイル1決定
- 一覧: `mise run decisions-index`(ADR と小さな決定の索引を標準出力に出す。索引はコミットしない。コミットすると、また衝突する)
- 2026-11-05 より前の決定は、`docs/DECISIONS.md` の「小さな決定」にある(そのまま残す)

```markdown
# <決定を一言で>

- 日付: YYYY-MM-DD
- Issue: #<番号>(なければこの行を省く)
- 決定: ...
- 理由: ...
- 関連: ADR-NNNN A<連番>(なければこの行を省く)
```
