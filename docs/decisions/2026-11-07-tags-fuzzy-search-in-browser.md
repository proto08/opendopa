# タグ名のあいまい検索はブラウザ側の文字列マッチで行う

- 日付: 2026-11-07
- Issue: #157
- 決定: あいまい検索は、`apps/web/lib/tagSearch.ts` の純粋関数で行う(正規化したうえで、`label` の前方一致 4、`label` の部分一致または `yomi` の前方一致 3、`yomi` の部分一致 2、2 文字以上の飛び飛び一致 1。同点は `count` の多い順)。`GET /api/tags` で全件(件数つき)を 1 回取り、画面を開いている間だけ持つ。DB の拡張(pg_trgm など)、ベクトル検索、サーバー側の検索 API は使わない。
- 理由: タグは数十〜百件程度なので、全件を送っても小さく、入力のたびに通信しなくて済む。ベクトル計算を Next.js に書かない約束(§0.2)にも触れない。
- 関連: `docs/hashtag_design.md` §2、§7
