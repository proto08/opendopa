# 地方ブロックと運輸局のタグは作らない

- 日付: 2026-11-07
- Issue: #157
- 決定: `#東北` のような地方ブロックのタグと、鉄道の `JURISDICTION`(運輸局)から作る `#関東運輸局` のタグは作らない。`region` のタグは都道府県だけ。`rail_*` には地域タグを付けず、データ種別(`#鉄道`)だけを付ける。
- 理由: 地方ブロックは元データにない地名で、都道府県からの対応表を持つことになる(設計書 §3.3「元データにない地名を作らない」)。運輸局は都道府県ではなく、`region` に混ぜると「地域で絞ると鉄道だけ出なくなる」理由が分かりにくくなる。ハッカソンの範囲では、都道府県だけで足りる。
- 関連: `docs/decisions/2026-11-07-pipeline-tags-region-columns.md`、`docs/hashtag_design.md` §3.1、§11
