# README にパイプラインの実行方法・デモの手順・免責を置き、ローカルの音声は対象外とする

- 日付: 2026-11-07
- Issue: #62
- 決定:
  - README に、パイプラインの実行順(`profile` → `generate` → `tts` → `embed` → `publish`、`all`)、環境変数の切り替え、`out/` の中身、入っているデータセットと本数、デモの手順、免責・クレジットを書く。実行順は `embed` を `tts` のあとにする(`all` と同じ。`2026-11-06-all-order-tts-before-embed.md`)。
  - ローカルのデモは `TTS_PROVIDER=none`(字幕とコメントのみ)を前提にする。ローカルの web には `MEDIA_BASE_URL`(`/media`)の配信経路がなく、音声は Blob に公開した環境でだけ再生できる。
  - 本数は 2026-11-07 時点の実データでの生成結果(14 データセット、1,845 本、除外 32 本)を書く。`docs/DECISIONS.md` には `accident` と `flightplan` の本数がないため、各データセットの決定の記録と、手元の `out/` の件数で補った。
  - Azure の手順は、既存の README・`infra/`・`Makefile` の読み取りに基づく。実環境では未確認と README に明記した。
- 理由: 受け入れ条件は「README の手順だけでセットアップ・パイプラインの実行・デモができる」こと。ローカルの音声配信は機能の追加になるため、範囲外(#62)とした。Azure の操作は、ユーザーの指示で実行していない。
