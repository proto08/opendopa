# タグの画面の細部(本数の表示・件数 0 のタグ・選択の確定)

- 日付: 2026-11-07
- Issue: #156
- 決定:
  - 虫眼鏡の「絞り込み中 N本」の N は、選んだタグの件数(`GET /api/tags` の `count`)の最小値とする。件数の表にないタグがあれば、本数は出さない。
  - 検索シートの候補には、件数 0 のタグを出さない(選ぶと必ず `pool_empty` になるため)。
  - 検索シートでの選択は、シートの中の下書きで持つ。候補を選ぶと適用して閉じ、`×` で外した分は閉じるとき(「閉じる」・Esc)に適用する。タグが変わらなければ、取り直さない。
  - 選べるタグは 4 つまで(BFF の上限と同じ)。上限に達したら、候補は選べず、案内を出す。
  - URL の `?tag=` が不正(未知の ID など)で最初の取得が失敗したときは、エラー画面に「タグを外して読み込む」を出す。
- 理由: AND の本数は、件数の表だけでは分からない(最小値は上限として正しい)。`×` のたびに取り直すと、シートの裏でフィードが入れ替わり、シートごと作り直されてしまう。
  - `pool_empty` が返ったときは、キューが空でも残っていても、最後の動画のあとに案内の 1 画面(「タグを全部外す」つき)を足す。最後の動画で止まって見えないようにするため(設計書 §10-5)。
  - 検索シートでタグが変わって取り直したあとも、最初の取得が終わったら先頭の画面の虫眼鏡へフォーカスを戻す(設計書 §6.3)。
