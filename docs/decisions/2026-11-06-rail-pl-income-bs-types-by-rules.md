# 鉄軌道の損益・貸借: 型はルールで決め、新しい op を足す

- 日付: 2026-11-06
- Issue: #54
- 決定: 3 データセットとも、型(黒字・赤字、初めて黒字・赤字、バス・不動産の事業の有無、自己資本比率の大きさ)は数字だけで決まるので、`decisions` の `template` の `fallback_rules`(`rules`)で選ぶ。「初めて黒字になった年」は `is_first_time`(データにある最初の年は初めてと言わない。このデータの中で初めて、という言い方にする)。op を足した: derived の `sign_label`、`format` の `abs` / `min_abs` / `max_abs`、stats の `prev_year_label`。`rank_in_group` の `<name>_n` を穴に使えるようにした。選定は YEAR の大きい順(最新年度中心)を点数の主にして、区分(`CATEGORY` / `COMPANY_SIZE`)でばらす。
- 理由: 数字の符号の判断に LLM を使うと、元データと食い違う型を選びうる。黒字・赤字の言葉と前年の符号は、穴に入れる文字列として機械的に作る必要があり、既存の op では作れなかった。
