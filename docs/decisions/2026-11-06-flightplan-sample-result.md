# flightplan(サンプル 100 件)の生成結果

- 日付: 2026-11-06
- Issue: #56
- 決定: サンプルの `generate`(`--provider rules`)の結果は、生成 100 本・除外 0 行(型は `night` 89 / `other` 11、推定 17.5〜21.4 秒、数字の不一致 0)。サンプルは全件が目的「農業」・特徴に「物件投下」で、フラグなしの行も重複した原稿もなかったため、除外は 0。除外の経路(フラグなし → `filter`)は合成データのテストで確かめている。
- 理由: 受け入れ条件「生成件数・除外の内訳を記録する」のため。サンプルが偏っているので、全量のデータが届いたら再実行して内訳を見直す。
