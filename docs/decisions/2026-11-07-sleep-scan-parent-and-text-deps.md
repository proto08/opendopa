# sleep-scan: 親イシューと、文章で書かれた依存を、実装の対象から外す

- 日付: 2026-11-07
- 決定:
  - PR が扱うイシューは、説明欄の `Closes/Fixes/Resolves/Refs #N` に加えて、タイトルの `(#N)` でも判定する(説明欄が別のイシューを指す PR でも、二重に実装しない)
  - 他のイシューから「親イシュー: #N」と指されているイシューは、親として扱い、実装の対象にしない(`waiting.parent_issues`)
  - 「## 依存」に、前提として読めない文章(「…のあと」など。「なし」を除く)があるイシューは、機械では判断できないので、実装の対象にせず、人が見る(`waiting.text_dependency`)
- 理由: 2026-11-07 の実行で、PR #169(説明欄が `Refs #146`、タイトルが `(#156)`)がある #156、#151 の PR が未マージの #152、親の #145 を、実装の対象に数えた。実装担当を起動する前に気づけたが、機械で防げる
