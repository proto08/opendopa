# シーンJSONの tags は必須にし、タグの付与までは pipeline が空配列を出す

- 日付: 2026-11-07
- Issue: #150
- 決定: `tags` を必須にした。タグを付ける処理が入るまで、pipeline(`scene.py`)は `tags: []` を出す。`Tag.id` は `^[a-z]+:[a-z0-9_-]+$`、`kind` は `dataset` / `region` に限る。固定のフィクスチャにも `tags: []` を足した。
- 理由: 設計書 §4.1 は必須・なければ空配列としている。必須にすると既存の出力が検証で落ちるので、付与の Issue より前でも通るよう空配列を出しておく。
