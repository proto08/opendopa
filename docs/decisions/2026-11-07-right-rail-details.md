# 右レールのいいね・シート・再生停止の細部

- 日付: 2026-11-07
- Issue: #50
- 決定:
  - いいねは `POST /api/like` に状態を送る。同じ状態は重ねて送らず、送信中に押されたら終わってから最後の状態だけ送る(`lib/likeSync.ts`)。送信に失敗したら、表示をサーバー側の状態に戻す。初期状態は `/api/feed` の `taste.log` の `liked`。
  - シートの表示中は `ScenePlayer.hold()` で再生を止め、閉じたら `release()` で続きから再開する。一時停止アイコンは出さない。利用者が先に止めていたら、閉じても再開しない。
  - シートは画面下に固定(`position: fixed`)で出し、`Esc`・背景のクリック・×で閉じる。Tab はシート内に閉じ込め、閉じたら開く前のフォーカスに戻す。開いている間は `j`/`k`/`l` などのショートカットを効かせない。
  - 「元データ」シートの「行番号」は `scene.source.ref`、データ名は `scene.source.datasetName` を出す。注記は「デモ用の仮データではなく、元データの値です。」。
  - 「好み」ボタンは常に DOM に置き、PC 幅(900px 以上)では CSS で隠す。シートの中身は #49 で置く(それまでは「準備中」)。
- 理由: 設計書 §3.3 の動作を満たしつつ、連打での重複送信と、シート表示中の音声・字幕の進みを防ぐため。
