# 広告風の画面をフィードに差し込む(画面側だけで行う)

- 日付: 2026-11-07
- Issue: #147
- 決定:
  - 広告のデータは `apps/web/lib/ads.ts` の固定の配列に置く(DB のテーブルにも、シーン JSON にもしない)。素材は文字だけで、ハッカソンと Project LINKS の告知のサンプル 2 件。
  - 差し込みは `Feed`(クライアント)が行う。動画が 5 本続くごとに、次の動画の前へ 1 つ入れる(次の動画がまだないときは入れない)。広告は配列の順に回る。`GET /api/feed` は変えず、広告を返さない。
  - 広告は `/api/view`・`/api/like` を呼ばず、`impressions` にも残らない。recsys に届く経路がないので、好みパネルと推薦に影響しない。広告の画面では `l`(いいね)は無視し、`j`/`k`・「次の動画へ」ボタンで動ける。
  - 広告の画面には「広告」のバッジを出す。動画ではないので「AI生成」ラベルと出典行は出さない。
- 理由: 受け入れ条件(推薦に影響しない)を、API・DB・recsys を触らずに構造で保証できる。ハッカソンの期間では、広告の管理や配信の仕組みより、見た目と挙動の確認を優先する。
