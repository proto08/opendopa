# 選定の score の式は許可リスト方式にする

- 日付: 2026-11-05
- Issue: #33
- 決定: 選定の `score` の式は 列 / `abs(列)` / `rank_desc(列)` / `rank_asc(列)` だけ。`rank_desc` は最大が 1、最小が 1/n の 0〜1(欠損は 0)。同点は `order_by`、なければ元の行の順。`score` がなく `seed` があればその種でシャッフル、どちらもなければ `order_by` の順。
- 理由: 重みづけ和で足せるよう順位を 0〜1 に正規化するため。式は eval を使わない許可リスト方式。
