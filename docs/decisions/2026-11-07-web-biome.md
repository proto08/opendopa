# web の lint・整形を ESLint から Biome に移す

- 日付: 2026-11-07
- Issue: #136
- 決定: `apps/web` の lint と整形を Biome(`@biomejs/biome` 2.6.5 固定)にした。`eslint`・`eslint-config-next`・`eslint.config.mjs` は削除した。lefthook、`mise run fmt`、`.claude/hooks/format.sh` も `biome check --write` に変えた。`packages/shared` は lint が型検査だけなので対象にしていない。
- 理由: CI の web ジョブの依存のインストールと lint を軽くするため。手元の `pnpm lint` は約 1.7 秒から約 0.15 秒になった。
- 移行前と同じ検査の強さを保つため、Biome の推奨ルールのうち、ESLint では検査していなかったものは外した。
  - `a11y` のグループ全体、`noNonNullAssertion`、`noArrayIndexKey`、`noAssignInExpressions`、`noCommaOperator`、`useIterableCallbackReturn`。
  - `useExhaustiveDependencies`: `useScenePlayer.ts` などで意図して依存を絞っており、ESLint では `eslint-disable` で許していた。Biome は `eslint-disable` を読まないため、ルールを外してコメントも消した。
- ESLint で検査していて、Biome では失われるもの: `eslint-plugin-react-hooks` の React Compiler 系のルールと、`@next/next` のルールのうち Biome の `next` ドメインにないもの。`rules-of-hooks` は Biome の `react` ドメインで残る。型を使う検査は元々なく、型は `tsc` が見る。
- 整形の差分(68 ファイル)は、中身を変えない整形だけを1つの commit にまとめた。
