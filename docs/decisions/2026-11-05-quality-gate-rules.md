# 品質ゲートの検査語と数字の照合の範囲

- 日付: 2026-11-05
- Issue: #34
- 決定:
  - 禁止表現は `gate.py` の `FORBIDDEN_PHRASES` に置く(「原因は」「原因が」「責任は」「責任が」「のせい」「せいで」「過失」「怠った」「おそらく」「違いない」「疑われ」「と推測」「と思われ」)。
  - 個人情報は、電話・メール・番地(`decider/rules.py` の `PII_PATTERNS` と共通)に、氏名らしい文字列(漢字2〜4字+「氏」「さん」)と郵便番号を足す。
  - 数字の照合は、原稿から数字を取り出し(全角は半角、桁区切りは除く、先頭の 0 は落とす)、元の行のすべての値(`derived` / `stats` の列を含む)と `numbers`(`display` / `value` / `inputs`)から取り出した数字の集合にあるかを見る。漢数字は「件・人・年・月」などの数える語の前にあるものだけを数字として読む(「一部」「万一」を数字にしない)。
  - 長さの検査は、シーンの `durationSec`(15秒に満たないときは15秒に延ばした後の値)が 15〜30 秒かを見る。
  - 検査に落ちた理由コードは、最初に落ちた検査の名前(`missing` / `unreplaced` / `number_mismatch` / `length` / `pii` / `forbidden`)。重複は `duplicate`(同じ原稿の2本目以降を除外する)。説明は `excluded.csv` の `detail` に全部残す。
- 理由: 語のリストは実装時に決める約束(Issue #34)。数字の集合は行の値から作るので、原稿が元データにない数字を出したときに確実に落ちる。禁止表現は、元の概要を引用した文にも当たるが、推測を語らない方針(設計書 §0.2)を優先して除外する。
